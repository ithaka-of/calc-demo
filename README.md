# Демо-калькулятор стоимости для сайта производителя

Одностраничный прототип: клиент собирает конфигурацию ползунками и кнопками,
видит цену сразу, отправляет заявку вместе с расчётом. Всё в одном `index.html` —
без сборки, библиотек и внешних зависимостей.

Живая версия: https://ithaka-of.github.io/calc-demo/

Показывается клиентам как иллюстрация к предложению: «на сайте считает сам
покупатель, менеджеру не нужно переспрашивать размеры и материалы».
Коэффициенты в демо условные, под конкретное производство подставляются свои.

## Что править под нишу

1. Заголовок и подзаголовок в начале `<body>`.
2. Диапазоны ползунков (`min` / `max` / `step`).
3. Варианты в группах опций: коэффициент в `data-k`, подпись для сводки в `data-n`.
4. Константу `BASE_M2` — база за единицу площади.
5. Текст кнопки заявки.

Формула: площадь фасада × база × коэффициенты опций + фиксированные надбавки,
с округлением до 500 ₽.

## Приём заявок

Страница статическая, своего бэкенда у неё нет, поэтому письмо отправляет релей
[FormSubmit](https://formsubmit.co) — адрес получателя задан в `FORM_ENDPOINT`.
Первое письмо на новый адрес сервис придерживает до подтверждения по ссылке.
