# Демо-калькулятор стоимости для сайта производителя и оптовика

Одностраничный прототип: клиент собирает конфигурацию или объём закупки, видит
цену сразу и отправляет заявку вместе с расчётом. Всё в одном `index.html` —
без сборки, фреймворков и внешних зависимостей, кроме шрифта.

Живая версия: https://ithaka-of.github.io/calc-demo/

Показывается клиентам как иллюстрация к предложению: «на сайте считает сам
покупатель, менеджеру не нужно переспрашивать размеры, материалы и количество».
Ставки и коэффициенты условные — под конкретную компанию подставляются свои.

## Что внутри

Два режима, в каждом свои ниши:

- **Под заказ** — кухни, шкафы и гардеробные, окна, двери, ограждения и ковка.
  Считается по погонному метру, площади фасада, площади проёма или за изделие.
- **Опт и дистрибуция** — сухие смеси (по расходу на площадь), крепёж и метизы
  (по объёму закупки), электрика и кабель (по метражу и позициям). Здесь
  показывается не только сумма, но и скидка за объём с явной экономией.

## Как добавить нишу

Ниши описаны данными в массиве `NICHES` в начале скрипта — разметка полей и
обработчики строятся автоматически. Чтобы добавить нишу, допишите объект:

```js
{
  id:'stairs', mode:'custom', tab:'Лестницы',
  title:'Лестница на заказ', unit:'считается за марш',
  fields:[
    {id:'steps', type:'range', label:'Ступеней', min:8, max:24, step:1, value:14, unit:'шт'},
    {id:'mat', type:'opts', label:'Материал', options:[['Сосна',1],['Дуб',1.8]]}
  ],
  calc:function(v){
    var base = v.steps.n * 9000;
    return {base:base, mult:base * v.mat.k - base, adds:0, rows:[
      ['Ступеней', v.steps.n + ' шт'], ['Материал', v.mat.n]
    ]};
  }
}
```

`calc` возвращает три слагаемых цены — `base` (основа), `mult` (надбавка
коэффициентов), `adds` (фиксированные допы); по ним рисуется полоска состава.
Необязательное поле `discount` (доля от 0 до 1) включает блок экономии — им
пользуются оптовые ниши.

## Приём заявок

Страница статическая, своего бэкенда у неё нет, поэтому письмо отправляет релей
[FormSubmit](https://formsubmit.co) — адрес получателя задан в `FORM_ENDPOINT`.
Первое письмо на новый адрес сервис придерживает до подтверждения по ссылке.
